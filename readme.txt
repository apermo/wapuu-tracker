GDPR-compliant, multisite-capable map of where Wapuus have travelled.

== Description ==

Wapuu Tracker maps where Wapuus have travelled on a GDPR-compliant, consent-gated
OpenStreetMap. Visitors and guests submit photo points of interest through a
moderation queue; a list view shows how many countries and continents each Wapuu
has visited. All front-end surfaces are Gutenberg blocks.

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/wapuu-tracker/`
2. Activate the plugin through the "Plugins" screen in WordPress
